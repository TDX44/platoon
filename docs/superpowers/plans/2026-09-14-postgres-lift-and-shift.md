# Postgres Lift-and-Shift (A0) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Platoon Accountability from SQLite to PostgreSQL with no change in behaviour, no change in schema shape, and no visible change to any user.

**Architecture:** The application is a Flask backend (`server.py`, ~1100 lines) plus a single-file vanilla-JS SPA (`index.html`, ~5000 lines). Only `server.py`, the test suite, the Docker/compose files and `scripts/` change here — `index.html` is touched once, in Task 1, for the environment banner and nowhere else. Work happens on a new parallel dev stack at `platoondev.carr7.com`; production keeps serving from SQLite the entire time and cuts over once, reversibly, at the end.

**Tech Stack:** Python 3.11, Flask, psycopg 3 (`psycopg[binary]`, `psycopg_pool`), PostgreSQL 17 in Docker Compose, gunicorn `-w 2`, Cloudflare Tunnel.

**Spec:** `docs/superpowers/specs/2026-09-14-postgres-migration-design.md`
**Context:** `docs/superpowers/specs/2026-09-14-multi-tenant-roadmap.md`

## Global Constraints

- **Production must keep working throughout.** Never run `docker compose` in `/opt/homelab/platoon` on prodsrv02 until Task 9. All dev work happens in `/opt/homelab/platoon-dev`.
- **No schema redesign.** `platoon TEXT` stays. No `units` table. That is project A1.
- **No RLS policies in A0.** A0 builds the connection plumbing RLS will need and establishes non-owner table ownership. Policies come in A1.
- **Timestamps stay TEXT** in the `'YYYY-MM-DD HH24:MI:SS'` shape. Do not convert to `timestamptz` — that reopens the duty-day behaviour that `app_now()` / `app_stamp()` / `org_timezone` already solve and `tests/test_timezone.py` guards.
- **Identity columns are `GENERATED BY DEFAULT`, never `ALWAYS`.** The backup-restore route at `server.py:1999` and `server.py:2046` inserts explicit `id` values; `ALWAYS` would reject them.
- **`index.html` is modified only in Task 1.** If a later task seems to require it, stop — something is wrong.
- **No new runtime dependency beyond psycopg.** `requirements.txt` is the production install list. `gunicorn` stays Docker-only; Playwright stays dev-only.
- **Tests are standalone assert scripts run directly** (`python tests/test_x.py`), not pytest. There is no test framework and none is being added.
- Every task ends with a commit. Branch for all of A0: `postgres-port`.

Create `tests/dbharness.py`:

```python
"""Give each test its own isolated Postgres schema.

Each test used to set DATA_DIR to a fresh temp directory and get a private
SQLite file. The Postgres equivalent is a private *schema* in one shared
database: same isolation, one server. Call setup() before importing server,
teardown() at the end of main().
"""
import os
import secrets

import psycopg

DEFAULT_URL = 'postgresql://platoon_owner:platoon@127.0.0.1:5432/platoon'


def admin_url():
    return os.environ.get('TEST_DATABASE_URL', DEFAULT_URL)


def setup():
    """Create a throwaway schema and point DATABASE_URL at it."""
    schema = 'test_' + secrets.token_hex(6)
    with psycopg.connect(admin_url(), autocommit=True) as conn:
        conn.execute(f'CREATE SCHEMA "{schema}"')
    url = admin_url()
    sep = '&' if '?' in url else '?'
    os.environ['DATABASE_URL'] = f'{url}{sep}options=-csearch_path%3D{schema}'
    os.environ['MIGRATION_DATABASE_URL'] = os.environ['DATABASE_URL']
    return schema


def teardown(schema):
    with psycopg.connect(admin_url(), autocommit=True) as conn:
        conn.execute(f'DROP SCHEMA IF EXISTS "{schema}" CASCADE')
```

- [ ] **Step 4: Translate the CREATE TABLE statements**

`CREATE TABLE IF NOT EXISTS` is valid Postgres and stays. Apply these three substitutions across all nine blocks:

- `INTEGER PRIMARY KEY AUTOINCREMENT` → `INTEGER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY` (six occurrences). **`BY DEFAULT`, not `ALWAYS`** — the restore route inserts explicit ids and `ALWAYS` would reject them.
- `TEXT DEFAULT (datetime('now', 'localtime'))` → `TEXT DEFAULT (to_char(now(), 'YYYY-MM-DD HH24:MI:SS'))` (four occurrences). Identical string shape to what `app_stamp()` writes.
- Double-quoted string literals such as `DEFAULT ""` and `DEFAULT "2nd"` → single quotes, `DEFAULT ''` and `DEFAULT '2nd'`. Postgres reads double quotes as identifiers, so `DEFAULT "2nd"` is a column reference and fails.

- [ ] **Step 3: Convert `INSERT OR IGNORE` and `INSERT OR REPLACE`**

Eight sites: lines 1155, 1960, 1999, 2014, 2023, 2031, 2036, 2046.

The two seeds at former lines 417 and 426 are **inside `init_db()` and were converted in Task 3** — Task 3 owns every SQL statement inside `init_db()`, Task 4 owns everything outside it. Do not convert them twice.

`INSERT OR IGNORE INTO settings (key, value) VALUES (%s, %s)` becomes:

```sql
INSERT INTO settings (key, value) VALUES (%s, %s) ON CONFLICT (key) DO NOTHING
```

`INSERT OR REPLACE INTO settings (key, value) VALUES (%s, %s)` becomes:

```sql
INSERT INTO settings (key, value) VALUES (%s, %s)
ON CONFLICT (key) DO UPDATE SET value = EXCLUDED.value
```

Postgres requires a named conflict target, so use the real key of each table: `settings` conflicts on `(key)`, `users` on `(id)`, `personnel_profile` on `(person_id)`, `scheduled_events` on `(id)`. For the wide restore inserts (1960, 1999, 2014, 2023, 2046) the `DO UPDATE SET` clause must list every non-key column as `col = EXCLUDED.col`; build it from the same `cols` list the code already uses for the column list.

Create `scripts/sqlite-to-pg.py`:

```python
"""Copy one SQLite database into Postgres. Run once, at cutover.

Usage: python scripts/sqlite-to-pg.py /path/to/accountability.db

Reads MIGRATION_DATABASE_URL (or DATABASE_URL) for the destination. The target
schema must already exist — start the app once so init_db() creates it.
"""
import os
import sqlite3
import sys

import psycopg
from psycopg.rows import dict_row

# Parents before children: personnel_profile and scheduled_events reference
# personnel, so they cannot go first.
TABLES = [
    'personnel', 'personnel_profile', 'settings', 'users',
    'audit_log', 'duty_roster', 'scheduled_events', 'invites', 'report_history',
]

# Tables whose id comes from an identity sequence that must be advanced past
# the highest copied id.
SEQUENCED = ['personnel', 'users', 'audit_log', 'duty_roster',
             'scheduled_events', 'report_history']


def main():
    if len(sys.argv) != 2:
        sys.exit(__doc__)
    src_path = sys.argv[1]
    dest_url = os.environ.get('MIGRATION_DATABASE_URL') or os.environ['DATABASE_URL']

    src = sqlite3.connect(src_path)
    src.row_factory = sqlite3.Row
    dest = psycopg.connect(dest_url, row_factory=dict_row)

    counts = {}
    for table in TABLES:
        try:
            rows = src.execute(f'SELECT * FROM {table}').fetchall()
        except sqlite3.OperationalError:
            print(f'  {table}: absent in source, skipped')
            continue
        if not rows:
            counts[table] = 0
            print(f'  {table}: 0')
            continue

        cols = list(rows[0].keys())
        collist = ', '.join(f'"{c}"' for c in cols)
        ph = ', '.join(['%s'] * len(cols))
        with dest.cursor() as cur:
            for row in rows:
                cur.execute(
                    f'INSERT INTO {table} ({collist}) VALUES ({ph}) ON CONFLICT DO NOTHING',
                    tuple(row[c] for c in cols))
        counts[table] = len(rows)
        print(f'  {table}: {len(rows)}')

    for table in SEQUENCED:
        if counts.get(table):
            dest.execute(
                f"SELECT setval(pg_get_serial_sequence('{table}', 'id'), "
                f'COALESCE((SELECT MAX(id) FROM {table}), 1), true)')

    dest.commit()

    failed = False
    for table, expected in counts.items():
        got = dest.execute(f'SELECT COUNT(*) AS n FROM {table}').fetchone()['n']
        if got != expected:
            print(f'MISMATCH {table}: source {expected}, destination {got}')
            failed = True
    dest.close()
    src.close()

    if failed:
        sys.exit('migration verification FAILED — do not cut over')
    print('migration verified')


if __name__ == '__main__':
    main()
```
