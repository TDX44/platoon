# Platoon Manager for iOS

A thin native shell around the web app. It opens `https://app.platoonmanager.com`
in a full-screen web view (Capacitor 8, `server.url` in `capacitor.config.json`),
so **every deploy of the site reaches the app at once** and the app only needs
rebuilding for native changes or when a TestFlight build expires (90 days).

Bundle ID `com.platoonmanager.app`. Home-screen name "Platoon Mgr".

## Build and upload to TestFlight (on the Mac)

One-time:

1. Install Xcode (from the App Store) and Node 22+.
2. In [App Store Connect](https://appstoreconnect.apple.com) → Apps → **+** → New App:
   platform iOS, name "Platoon Manager", bundle ID `com.platoonmanager.app`
   (register it under Certificates, IDs & Profiles → Identifiers first if it is
   not offered), SKU anything (e.g. `platoon-ios`).

Each build:

```bash
cd mobile
npm ci              # first time, or after package.json changes
npx cap sync ios    # copies config + plugins into the Xcode project
npx cap open ios    # opens App.xcodeproj in Xcode
```

In Xcode:

1. Select the **App** target → **Signing & Capabilities** → tick *Automatically
   manage signing* and pick your team (the Resyrv account is fine; the bundle ID
   is what matters, and the app can be moved to another account later with
   App Transfer).
2. **General** → bump **Build** (1, 2, 3, …) every upload; App Store Connect
   refuses a build number it has seen. **Version** (1.0) only changes for a
   release.
3. Choose **Any iOS Device (arm64)** as the run destination, then
   **Product → Archive**.
4. In the Organizer window that opens: **Distribute App → App Store Connect →
   Upload**. Accept the defaults.
5. After 5–15 minutes the build appears under the app's **TestFlight** tab.
   Add yourself under *Internal Testing* and install it with the TestFlight app
   on your phone. External testers (people not on the App Store Connect team)
   need a one-time Beta App Review, usually under a day.

Export compliance is already answered (`ITSAppUsesNonExemptEncryption = NO`:
the app only uses HTTPS), so no question pops up per build.

To try it in the simulator instead: pick an iPhone simulator in Xcode and press
Run. Google sign-in works there too.

## How sign-in works

Email and password sign-in happen inside the app, exactly as on the web.

Google refuses to sign anyone in inside an embedded web view
(`disallowed_useragent`), so in the app **Continue with Google** opens the site
in an in-app Safari sheet instead:

1. The app opens `/?native-signin=<random nonce>` in the sheet.
2. The user signs in there (Google or email — it is just the website).
3. The page calls `POST /api/auth/native-ticket`, which asks Clerk's Backend API
   for a 60-second, single-use sign-in token for the account it is signed in as.
4. The page navigates to `platoonmanager://signin?ticket=…&nonce=…`; iOS hands
   that to the app, which closes the sheet, checks the nonce is the one it sent
   and signs in with Clerk's `ticket` strategy.

Needs `CLERK_SECRET_KEY` in the server's `.env` (already set in production for
the platform admin check). The sheet keeps its own session, so the next Google
sign-in on that phone is one tap; to switch Google accounts, sign out inside
the sheet's page first.

Known limit: a custom URL scheme is not exclusive on iOS, so another app could
register `platoonmanager://` too. Universal Links fix that and are the next step
before a public App Store release (they need an `apple-app-site-association`
file served with the Apple team ID).

## What the app hides

Apple requires its own in-app purchase for any subscription sold inside an app,
so the app sells nothing: the billing banner, Billing page, plan picker and
every link to Stripe are hidden under `html.native-app` (set when the user agent
carries `PlatoonManagerApp/`, which `capacitor.config.json` appends). A locked
account sees a plain "subscription isn't active" screen with Sign out. Billing
is managed on the website.

## Other known limits

- **File downloads** (Export CSV, backup download) do not work in the web view
  yet; use the website for those.
- No push notifications yet (email alerts still work). Adding them is the
  natural next native feature, and also what makes an App Store review less
  likely to call this "just a website".
- Offline: if the site cannot be reached the app shows `www/offline.html` with
  a Try again button.

## Files

- `capacitor.config.json` — app id, name, the URL it loads, the user-agent tag.
- `ios/App/App/Info.plist` — display name, the `platoonmanager` URL scheme,
  export compliance.
- `ios/App/App/Assets.xcassets` — the app icon and launch splash, generated by
  `scripts/make-icons.py` from `images/app-logo.png`; do not edit by hand.
- `www/` — only `offline.html` is ever shown.

Anything under `ios/` that `npx cap sync` regenerates (`App/App/public`,
`App/App/capacitor.config.json`, `config.xml`) is gitignored.
